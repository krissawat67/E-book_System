# KU-Goodbook

**KU-Goodbook** คือโปรแกรมอ่านหนังสือและนิยายบนเดสก์ท็อป พัฒนาด้วยภาษา Java และ Java Swing ออกแบบมาเพื่อมอบประสบการณ์การอ่านที่สบายตาด้วยโทนสีกระดาษ (Paper Theme) พร้อมส่วนติดต่อผู้ใช้ที่ใช้งานง่ายสำหรับการอ่านหนังสือออนไลน์[cite: 1, 9, 10]

---

## ข้อมูลโปรแกรม (Overview)

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **ประเภทโปรแกรม** | Desktop Application |
| **ภาษาที่ใช้** | Java |
| **GUI Framework** | Java Swing |
| **ธีมการแสดงผล** | Paper Theme (สีกระดาษถนอมสายตา) |
| **การจัดเก็บข้อมูล** | ไฟล์ CSV (จัดเก็บและบันทึกข้อมูลในเครื่อง)[cite: 10] |
| **สถานะโปรเจกต์** | UI Prototype (ตัวอย่างส่วนติดต่อผู้ใช้) |

---

## ขอบเขตการทำงานของระบบ (System Workflow)

โปรแกรมทำงานผ่านระบบจัดการไฟล์ CSV ภายในเครื่อง โดยไม่มีการต่อเซิร์ฟเวอร์ภายนอก แบ่งกระบวนการทำงานหลักออกเป็น 4 ส่วน[cite: 10]:

1. **การนำเข้าข้อมูล (CSV Import):** โหลดไฟล์ CSV เพื่อเพิ่มหรืออัปเดตหนังสือและเนื้อหา โดยมีระบบตรวจสอบรูปแบบและรหัสซ้ำก่อนบันทึกลงหน้าคลัง[cite: 10]
2. **การค้นหาและการอ่าน (Search & Reading):** ค้นหาตามชื่อเรื่องหรือผู้แต่ง เลือกอ่านบทต่างๆ พร้อมบันทึกตำแหน่งการอ่าน[cite: 10]
3. **การบันทึกเรื่องโปรด (Saved Books):** บันทึกหนังสือลงในไฟล์เพื่อนำกลับมาอ่านต่อหรือลบรายการออก[cite: 10]
4. **ระบบคะแนนและรีวิว (Rating & Review):** ให้คะแนน 1-5 ดาว และเขียนข้อความรีวิว โดยระบบจะบันทึกและคำนวณคะแนนเฉลี่ยใหม่เพื่อแสดงผลให้ทุกบัญชีเห็น[cite: 10]

---

## ฟังก์ชันการใช้งานหลัก

### 1. หน้าแรก (Home Screen)
- แสดงรายการหนังสือยอดนิยม 8 เรื่อง
- ช่องค้นหาหนังสือตามชื่อเรื่องหรือชื่อผู้แต่ง[cite: 10]
- แถบกรองหมวดหมู่ (วรรณกรรม, แฟนตาซี, ปรัชญา, ทั่วไป, การศึกษา)
- ตัวเลือกจัดเรียงลำดับรายการหนังสือ
- ปุ่มสลับโหมดกลางคืน (Night Mode) บริเวณมุมขวาบน

### 2. หน้ารายละเอียดหนังสือ (Book Detail Screen)
- แสดงข้อมูลหนังสือครบถ้วน (ภาพปก, ชื่อเรื่อง, ผู้แต่ง, ปีที่พิมพ์, หมวดหมู่, คะแนนเรตติ้ง)[cite: 10]
- รายการสารบัญพร้อมปุ่มเลือกอ่านแต่ละบท[cite: 10]
- ส่วนให้คะแนนเรตติ้ง (1-5 ดาว)[cite: 10]
- ช่องพิมพ์ข้อความรีวิว ปุ่มส่งรีวิว และส่วนแสดงความคิดเห็นจากผู้อ่าน[cite: 10]

### 3. หน้าอ่านหนังสือ (Reader Screen)
- แสดงเนื้อหาจัดวางแบบแบ่งย่อหน้า เว้นระยะบรรทัดอ่านง่าย
- ปุ่มปรับขนาดตัวอักษร A- (ลดขนาด) และ A+ (เพิ่มขนาด)
- ปุ่มนำทางเปลี่ยนบทอ่าน (ตอนก่อนหน้า / ตอนถัดไป)[cite: 10]
- บันทึกตำแหน่งการอ่านล่าสุดอัตโนมัติ[cite: 10]

### 4. หน้ารายการโปรด (Favorites Screen)
- ศูนย์รวมรายการหนังสือที่บันทึกไว้[cite: 10]
- ช่องค้นหาในรายการโปรด และตัวเลือกการจัดเรียง
- ปุ่มจัดการอ่านต่อหรือนำรายการออก[cite: 10]

### 5. ระบบบัญชีผู้ใช้ (Auth Screens)
- **หน้าเข้าสู่ระบบ (Login):** ฟอร์มลงชื่อเข้าใช้ พร้อมตัวเลือก "จำฉันไว้"
- **หน้าสมัครสมาชิก (Register):** ฟอร์มลงทะเบียน พร้อมปุ่มยอมรับเงื่อนไขการใช้งาน
